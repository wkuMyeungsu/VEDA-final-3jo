# 지게차 사각지대 충돌 방지 시스템

한화비전 VEDA 프로그램 팀 프로젝트 — 지게차 사각지대에서 사람을 감지해
충돌을 방지하는 시스템.

## 트랙 구조

| 폴더 | 담당 역할 |
|---|---|
| server/ | 이벤트 수신, 좌표 변환, 위험 판정, RTSP 수신 |
| cctv/ | ArUco 마커 검출, WiseAI 객체 검출 (예정) |
| forklift-device/ | 운전자 단말, 경고 출력 (예정) |
| operator-device/ | 관제 대시보드 (예정) |
