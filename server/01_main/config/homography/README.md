# 운영용 호모그래피 산출물

호모그래피 보정 웹 앱은 채널별 보정이 성공하면 결과를
`homography_channel_<channel>_mm.json` 이름으로 이 디렉터리에 원자적으로 교체한다.
이 파일은 카메라 실물 보정에서 나오는 배포 데이터이므로 Git에 임의 행렬을 넣지 않는다.
파일이 없거나 계약이 틀리면 서버는 항등행렬이나 더미 좌표로 대체하지 않고,
해당 채널 프레임을 위치 미확정으로 처리한다.

필수 런타임 계약은 다음과 같다.

```json
{
  "world_unit": "mm",
  "H_pixel_to_world": [[0, 0, 0], [0, 0, 0], [0, 0, 0]],
  "image_size": {"width": 2592, "height": 1520}
}
```
