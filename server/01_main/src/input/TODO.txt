── 남은 일 (하드웨어 필요, 코드로는 불가) ──
[ ] 실물 카메라 RTSP 스트림 연결 -> XML 이 실제로 도달하는지 확인.
    실행:
      forklift_safety_server "rtsp://<user>:<password>@192.168.0.3:554/0/onvif/profile2/media.smp"
    (RTSP URL·camera_id 등은 config/camera_config.json 에 있음: rtsp_url 위와 동일,
     camera_id "cam_01", metadata_topic tns1:OpenApp/ArUCo_Detection/MarkerDetected,
     ntp_server 192.168.0.1.)
    리눅스/윈도우 모두 giolibproxy 로딩 지연으로 RTSP 연결이 느려질 수 있으므로,
    실행 전 환경변수 GIO_USE_PROXY_RESOLVER=dummy 설정을 권장한다.
[ ] object 경로 / aruco 경로 각각의 delta_ms 로그 실측값을 확정해 Confluence 에 기록한다.
[ ] 위 실측 지연 폭을 근거로 Task 27(world 좌표 전달 방식: 함수 호출 vs IPC)을 최종 결정한다.
