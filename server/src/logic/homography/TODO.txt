── 할 일 ──
[ ] homography.hpp / homography.cpp 작성 — 픽셀 -> 월드 3x3 원근 변환
    이 서버 빌드는 OpenCV를 링크하지 않는다(GStreamer/pugixml/SQLite만). 그래서
    cv:: 대신 동일 수식을 순수 C++17로 구현한다. 행렬은 row-major 3x3, 인덱스
    [0 1 2 / 3 4 5 / 6 7 8] 로 cv::getPerspectiveTransform 출력과 같은 배치로 맞춘다.
    -> 나중에 실측 캘리브레이션 행렬(9계수)이 나오면 그대로 끼워 넣을 수 있다.
[ ] apply(PixelPoint) -> WorldPoint
    [X' Y' W]^T = H * [u v 1]^T, 결과 = (X'/W, Y'/W).
    원근 분모 W가 0에 수렴하면(지평선/무한원점 방향) 변환 불가로 처리한다
    (성공 여부 플래그를 돌려주고 실패 시 {0,0} 반환).
[ ] estimateFromCorrespondences(픽셀 4점, 월드 4점) -> 행렬
    대응점 (u,v)->(X,Y) 하나가 방정식 2개를 준다(h8=1 고정):
      h0*u + h1*v + h2 - h6*u*X - h7*v*X = X
      h3*u + h4*v + h5 - h6*u*Y - h7*v*Y = Y
    4점 = 8식 8미지수를 부분 피벗 가우스 소거로 푼다(= cv::getPerspectiveTransform).
    세 점이 일직선이면 특이행렬 -> 실패 반환.
[ ] 기본값 = 항등 행렬(픽셀=월드). 실측 캘리브레이션 전 Plan B 자리표시자로,
    행렬이 없어도 파이프라인 전 구간이 돌아가게 한다.
